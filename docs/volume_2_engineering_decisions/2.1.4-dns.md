# 2.1.4 Decisions: DNS: BIND

Topics:

## 2.1.4.1 Where Kea registers DHCP hostnames

- **Decision:** A separate dynamic subzone per DHCP scope (`dhcp.<domain>`, per-VLAN subzones with 802.1X); never the rendered zones ([1.10.1.1](../volume_1_description_and_architecture/1.10.1-kea-design.md#11011-kea-dhcp)).
- **Shapes:** 1.4, 1.10
- **Made:** 2026-09-27 to 2026-10-01, while fabric was designed, by the owner.
- **Why:** dynamic updates never touch the zones fabric renders from settings, so a render cannot lose a lease's name and a lease cannot overwrite a record.
- **Status:** In force.

## 2.1.4.2 Which of the site's DNS records the landing page links to, and how

- **Decision:** **Only records marked for it**, each with an optional port, path and label (`https://<name>.<domain>[:port][/path]`); shown to everyone on the LAN like the rest of the page.
- **Shapes:** 1.4, 4.4
- **Made:** 2026-10-07, by the owner, in 0.6.1; design: 1.4.2.2.
- **Why:** the owner adds records for the machines on the network (a Proxmox host, say) and wants the landing page to link to them; only some records are worth a link.
- **Status:** In force.

## 2.1.4.3 The instructions page lives at info.<domain>, over HTTP too

- **Decision:** `landing_page_cname` defaults to `info`. `info.<domain>` answers on HTTP and HTTPS with no forced redirect, with the instructions, the CA files and the root's SHA-256 fingerprint; everything else stays HTTPS-only. `<domain>` and the host's own name redirect (301) to it.
- **Shapes:** 1.4, 1.5, 3.3, 4.4
- **Made:** 2026-10-08, by the owner, for 0.6.3.
- **Why:** a new device can fetch the CA over plain HTTP and check it before trusting it (2.3.5.3.6).
- **Status:** In force; built in 0.6.3 (1.4.2.3).

## 2.1.4.4 Dynamic DNS for public records at Cloudflare

- **Decision:** fabric keeps a list of public records at Cloudflare pointed at the house's current IPv4 address, the proxy setting kept per record (never changed by fabric on its own), checked every 5 minutes against Cloudflare's trace and a second source; run on the core host by default or on another host the owner selects. IPv6 later.
- **Shapes:** 1.4, 1.2
- **Made:** 2026-10-08, by the owner, for 0.6.3.
- **Why:** the house's address is dynamic and hidden behind Cloudflare's proxy; fabric takes over the edge machine's own client (2.3.5.3.16).
- **Status:** In force; **moved to 0.7 by the owner on 2026-10-08** (2.1.1.39): not built in 0.6.3. **Moved again, to the release after 0.7, by 2.1.1.42 on 2026-10-10.** **Placed in 0.11 by 2.1.1.45 on 2026-10-10.**
