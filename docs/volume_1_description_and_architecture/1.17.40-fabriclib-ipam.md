### 1.17.40.1.1 `check_address(addr, subnet, plan, current=None)`

| | |
|---|---|
| Purpose | one address of a subnet checked against the model's rules (manual 1.10.4.3.2): one address, one claim (a static address, a reservation or the gateway; a second is refused naming the first); inside a dhcp range only a reservation; a static address outside every static range is warned about, never refused; a reservation has a MAC, unique among the site's reservations; a name is one DNS label, and one published in DNS (an A and a PTR in the site's zone, 1.10.4.5; a reservation's too, beside the name DHCP registers in dhcp.<domain>, 2.1.10.17) is unique among the site's. |
| Inputs | addr — {"ip", "kind", "name", "mac", "owner", "notes", "dns", "options"}; subnet — the subnet's plan entry (cidr, gateway, dhcp, ranges, addresses); plan — the site's plan (every subnet's addresses, for MACs and DNS names); current — the address being changed (its own claim is not a second one), None for a new one. |
| Returns | (the address normalized {"ip", "kind", "name", "mac" (lower-case, colons), "owner", "notes", "dns", "options"}, warnings: list of str). |
| Fails | ValidationError: not a host of the subnet, an unknown kind, a second claim (named), a non-reservation in a dhcp range, a reservation without a MAC or with a MAC another reservation has, a bad MAC or name, DNS without a name, a DNS name another address publishes, an owner over one line, notes over 500 characters, bad options. |
