## 1.2.5.1 Jinja2 Templates

All `.j2` files are rendered by the `fabricctl` deployment engine (`src/ux/cli/deploy.py`, and for the optional services `fabriclib/dhcp/deploy_kea.py`, `fabriclib/radius/deploy_freeradius.py`, `fabriclib/logs/deploy_fluentbit.py`; shared Jinja environment `fabriclib/common/jinja_env.py`) via `/tmp/fabric-render` into `/opt/<service>/`. The service folders hold only rendered output; the templates themselves stay in the installed tree (`/opt/fabric/jinja`).

| Template | Rendered to |
|----------|------------|
| `templates/vars.yaml.j2` | `/tmp/fabric-render/vars.yaml` (resolved vars — merged at run time) |
| `templates/<service>/docker-compose.yml.j2` | `/opt/<service>/docker-compose.yml` (e.g. nginx, bind9) |
| `templates/nginx/nginx.conf.j2` | `/opt/nginx/config/nginx.conf` |
| `templates/nginx/www/*/index.html.j2` | `/opt/nginx/www/{certs,landing,manual}/index.html` (certs: served at `info.<domain>/certs/` and `http://<host_ip>/certs/`, 1.5.1.5) |
| `templates/bind9/config/named.conf*.j2` | `/opt/bind9/config/named.conf*` |
| `templates/bind9/data/zone.j2` | `/opt/bind9/data/db.<zone>` (forward zones) |
| `templates/bind9/data/reverse-zone.j2` | `/opt/bind9/data/db.<reverse zone>` (`in-addr.arpa` /24 and `ip6.arpa` /64 PTR zones — auto-generated) |
| `src/containers/samba/*.py` | `/opt/samba/converge/` (copied, not rendered, by `fabriclib/samba/deploy_samba.py`; run inside the DC) |
| `templates/webui/webui.json.j2` | `/opt/webui/config/webui.json` |
| `packaging/images/webui/Dockerfile` + `src/webui/*.py` (installed as `jinja/webui/build/` and `lib/webui/`) | `/opt/webui/build/` (+ `app/`) — copied, not rendered; image `fabric/web:local` (container and unit `fabric-web`) |
| `packaging/images/<svc>/*` | `/opt/<svc>/build/` — copied, not rendered (local image layers) |
| `templates/systemd/wrapper.service.j2` | `/etc/systemd/system/<unit>.service` (one per service; `fabric.target` copied as is) |
| `templates/systemd/fabric-agent.service.j2` | `/etc/systemd/system/fabric-agent.service` |
| `templates/stepca/leaf.tpl.j2` | `/opt/stepca/data/templates/certs/leaf.tpl` |
| `templates/stepca/subca.tpl.j2` | `/opt/stepca/data/templates/certs/subca.tpl` |
| `templates/openbao/openbao.hcl.j2` | `/opt/openbao/config/openbao.hcl` |
| `templates/kea/*.conf.j2`, `freeradius/config/**`, `fluentbit/fluent-bit.yaml.j2` | `/opt/kea/config/`, `/opt/freeradius/config/`, `/opt/fluentbit/config/` (optional services) |
