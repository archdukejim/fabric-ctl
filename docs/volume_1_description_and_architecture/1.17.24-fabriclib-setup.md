| | |
|---|---|
| Purpose | copy what a reinstall must keep — config + secrets, the whole Step-CA (keys, database), every issued certificate/key, OpenBao's data with its key folder, and the domain (the DC's database and SYSVOL, with the Administrator's password file) — to a root-only folder. |
