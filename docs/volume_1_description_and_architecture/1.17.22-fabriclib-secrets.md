### 1.17.22.4.2 `import_secrets(v, secrets_file, token=None)`

| | |
|---|---|
| Purpose | Move fabric's secrets from the 0600 file into OpenBao (KV v2 fabric/secrets): write, read back, compare, and only when identical write the marker and shred the file. |
| Inputs | v — fabric vars for OpenBao; secrets_file — path of fabric-secrets.yml; token — OpenBao token, default a SETUP_CREDS AppRole login per call. |
| Returns | "imported" (written), "unchanged" (a restored file equal to what OpenBao holds) or "none" (no file: nothing to do). Idempotent. |
| Fails | ValidationError "<file> is empty; refusing to import it over fabric's secrets"; "fabric's secrets read back from OpenBao differ from the file; the file was kept"; read_vault_secrets / write_vault_secrets' ValidationError; yaml.YAMLError; OSError. |
| Feeds | setup/setup_openbao.py run. |
| Notes | the marker (0644, never secret itself) makes OpenBao the source of truth from then on (see secrets_in_openbao); it is written before the file is shredded. |
| Called by | `fabriclib.setup.setup_openbao.run` |
