## 1.3.3.1 Fixed API

`fabric-agent` answers only these routes (JSON over its unix socket). "any
sign-in" means any signed-in fabric user.

| Method | Route | Needs |
|---|---|---|
| GET | `/v1/version` | any sign-in |
| GET | `/v1/services` | `status:read` |
| GET | `/v1/host-changes` | `status:read` |
| GET | `/v1/relaxed-settings` | `status:read` |
| GET | `/v1/cert-warnings` | `status:read` |
| GET | `/v1/reminders` | `status:read` (what every administrator is reminded of: the break-glass password's file still on the host, 1.6.12.16.3; each local administrator account neither managed nor approved, 1.6.12.16.7) |
| GET | `/v1/security` | `security:raise` |
| GET | `/v1/zones`, `/v1/zones/<key>`, `/v1/reverse-zones`, `/v1/tsig` | `dns:read` |
| GET | `/v1/audit` | `audit:read` |
| GET | `/v1/dhcp` | `dhcp:read` |
| GET | `/v1/dns-filter` (the DNS filter's lists, rules and statistics, 1.12.2.13) | `dns:filter` |
| POST | `/v1/dns-filter/querylog` (a query-log search: `client`, `name`, `blocked`, `limit`) | `dns:querylog` |
| POST | `/v1/dns-filter/lists`, `/v1/dns-filter/lists/set` (a list ticked or unticked, 1.12.3.5), `/v1/dns-filter/lists/delete`, `/v1/dns-filter/rules`, `/v1/dns-filter/rules/delete`, `/v1/dns-filter/upstreams`, `/v1/dns-filter/groups`, `/v1/dns-filter/groups/delete`, `/v1/dns-filter/safe-search` (each saved and applied; lists and rules take an optional group, 1.12.2.15), `/v1/dns-filter/fetch` (the lists job started, 1.12.2.14) | `dns:filter` |
| GET | `/v1/radius`, `/v1/radius/guides` | `radius:read` |
| GET | `/v1/pki/{ca,issued}` | `pki:read` |
| GET | `/v1/devices` | `devices:read` |
| GET | `/v1/people` | `people:read` |
| GET | `/v1/domain` | `domain:read` |
| GET | `/v1/gpo` | `domain:read` |
| GET | `/v1/federation` | `federation:read` |
| GET | `/v1/vault`, `/v1/vault/{slots,devices}` | `vault:status` |
| POST | `/v1/events` (`LOGIN`, `LOGOUT`, `LOGIN_DENIED` only) | any sign-in |
| POST | `/v1/zones` (a new zone, 1.4.1.3), `/v1/zones/<key>/delete`, `/v1/zones/<key>/records`, `/v1/zones/<key>/records/delete`, `/v1/zones/<key>/records/link` (a record linked from the landing page, or not, 1.4.2.4), `/v1/apply` | `dns:write` |
| POST | `/v1/pki/{describe-csr,inspect}` | `pki:read` |
| POST | `/v1/pki/sign` | `pki:sign` |
| POST | `/v1/pki/revoke` | `pki:revoke` |
| POST | `/v1/pki/{issue,convert}` | `pki:issue` |
| POST | `/v1/tsig`, `/v1/tsig/<name>/{rotate,delete}` | `tsig:manage` |
| POST | `/v1/vault/rotate`, `/v1/vault/slots/{add-usb,add-security-key,add-hsm}`, `/v1/vault/slots/<id>/{test,remove}` | `vault:unlock` |
| POST | `/v1/devices` | `devices:enroll` |
| POST | `/v1/devices/<name>`, `/v1/devices/<name>/delete` | `devices:admin` |
| POST | `/v1/devices/<name>/certs` | `pki:link-device` |
| POST | `/v1/roles`, `/v1/roles/<name>`, `/v1/roles/<name>/delete` | `roles:admin` |
| POST | `/v1/people` | `people:create` |
| POST | `/v1/people/<uid>/reset` | `people:reset` (members of fabric groups: also `system:admin`) |
| GET | `/v1/images` (each service's image: running, validated, state) | `status:read` |
| GET | `/v1/pki/acme` (ACME for LAN machines: how, and the machines enrolled for DNS-01) | `pki:read` |
| POST | `/v1/jobs/doctor` (doctor's checks, as a job: answers its id) | `status:read` |
| POST | `/v1/jobs/images` (body: `action` update or rollback, `service`; a job) | `images:update` |
| GET | `/v1/jobs/<id>` (a job: running, done with its result, or failed with why) | any signed-in person, their own jobs only |
| POST | `/v1/people/<uid>/disable`, `/v1/people/<uid>/enable` | `people:disable` (members of fabric groups: also `system:admin`) |
| POST | `/v1/people/<uid>/delete` (body: `confirm`, the user name typed back) | `people:remove` (members of fabric groups: also `system:admin`) |
| POST | `/v1/people/<uid>/groups` (body: `action` add or remove, `group`) | `people:groups` (a fabric group: also `system:admin`) |
| POST | `/v1/machines` | `machines:admin` |
| POST | `/v1/machines/<name>/enable`, `/v1/machines/<name>/disable`, `/v1/machines/<name>/delete` | `machines:admin` |
| POST | `/v1/domain/password-policy` (the policy keys to change, checked as the command checks them, 1.6.5.25; the domain's default only: a request naming a tier is refused, the tiers' are set only on the host, 1.6.12.16.4) | `domain:admin` |
| POST | `/v1/gpo/search` | `domain:read` |
| POST | `/v1/gpo/set`, `/v1/gpo/clear` | `gpo:admin` |
| GET | `/v1/host-groups` (the site's host groups, their machines and sudo rules: 1.6.11.7), `/v1/sudo` (the site's sudo rules, each fabric's, the default or an admin's own) | `domain:read` |
| POST | `/v1/host-groups` (body: `name`), `/v1/host-groups/<name>/members` (body: `action` add or remove, `machine`), `/v1/host-groups/<name>/delete` | `machines:admin` |
| POST | `/v1/sudo` (body: `name`, `users`, `commands`, `run_as` lists, `hosts`: a host group or ALL), `/v1/sudo/<name>/delete` (fabric's rules only) | `sudo:admin` |
| POST | `/v1/dhcp/on`, `/v1/dhcp/off` (then the host firewall brought in line, 1.10.3.5), `/v1/dhcp/reservations`, `/v1/dhcp/reservations/<mac>/delete`, `/v1/dhcp/subnets`, `/v1/dhcp/subnets/{update,delete}`, `/v1/dhcp/options`, `/v1/dhcp/options/delete`, `/v1/dhcp/classes`, `/v1/dhcp/classes/<name>/delete` | `dhcp:write` |
| POST | `/v1/security/raise` (a raise only: a lowering is 400), `/v1/security/kerberos` | `security:raise` |
| GET | `/v1/settings` (the setup wizard: today's settings, the console-only ones read only, whether it is finished, 1.8.5), `/v1/settings/export` (the settings file) | `settings:admin` |
| POST | `/v1/settings/plan` (body: `form`, the wizard's fields, or `file`, a settings file: the plan, kept 15 minutes), `/v1/settings/apply` (body: `plan`, its id: one apply job, or the plan made again when stale), `/v1/settings/dismiss` (1.8.5.10) | `settings:admin` |
| POST | `/v1/radius/clients`, `/v1/radius/clients/<name>/{rotate,delete}`, `/v1/radius/people`, `/v1/radius/people/<group>/delete` | `radius:admin` |
