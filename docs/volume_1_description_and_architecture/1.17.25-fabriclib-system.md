### 1.17.25.12.5 `plan_memory(v)`

| | |
|---|---|
| Purpose | every installed service's memory limit, planned as a budget (manual 1.2.4.3, decision 2.1.1.47): host_ram_capacity less a reserve for the host is the budget; each service gets its floor, and what is left goes to the services with a weight, in proportion. Precedence for one service: its own `*_mem_limit` setting when the admin set one (that limit, fixed, no share; a value it held by default before 0.7.1 counts as not set), else its `memory_floors` / `memory_weights` entry, else the built-in floor and weight. The limits always add up to the budget (whole MB; what rounding leaves goes to the largest weight). |
| Inputs | v — settings: host_ram_capacity (GB), the install flags (_installed), memory_floors, memory_weights, openbao_mem_limit, kea_mem_limit, samba_mem_limit, freeradius_mem_limit, fluentbit_mem_limit, resolver_mem_limit, adguard_mem_limit (AdGuard Home's container limit: counted / BURST). |
| Returns | {"capacity_mb", "reserve_mb", "budget_mb", "limits": {service: MB per container}, "containers": {service: count}, "explicit": {service: MB} (the ones set by a `*_mem_limit`), "settings": {"<svc>_mem_limit": the admin's value or None}, "unassigned_mb": what no service took (only when no installed service has a weight), "bursts": {service: its container's limit, BURST times its share, for the services in BURST}, "over_mb": how far those limits together go past the budget during a burst}. |
| Fails | ValidationError: host_ram_capacity not a whole number; memory_floors / memory_weights not valid; a `*_mem_limit` that is not a size; the floors (and fixed limits) of the installed services do not fit the budget — naming the parts that could be turned off, what each frees, and the memory the plan needs. |
| Feeds | vars.yaml.j2 (memory_plan, through jinja_env), system/memory_limit_mb, setup/choose_plan, setup/set_ram_capacity, system/show_memory_plan. |
| Called by | `fabriclib.settings.plan_settings._limits`, `fabriclib.settings.plan_settings.plan_settings`, `fabriclib.setup.advanced.ask_memory.ask_memory`, `fabriclib.setup.set_ram_capacity._plan`, `fabriclib.system.memory_limit_mb.memory_limit_mb`, `fabriclib.system.show_memory_plan.show_memory_plan` |
