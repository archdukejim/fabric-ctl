### 1.17.25.1.1 `apply_changes(actor, source='cli')`

| | |
|---|---|

## 1.17.25.2 `src/fabriclib/system/control_stack.py`

### 1.17.25.2.1 `control_stack(verb)`

| | |
|---|---|
| Purpose | `fabricctl start\|stop\|restart\|status`: the whole stack through fabric.target (every fabric unit is PartOf it). |
| Inputs | verb — "start", "stop", "restart" or "status". |
| Returns | [] for start/stop/restart once systemctl succeeded; for status [(unit, state, container health)]: fabric.target first, then service_status() — no change is made. |
| Fails | ValidationError when systemctl fails or the verb is unknown; subprocess.TimeoutExpired after 900 s. |
| Feeds | cli main (prints the rows). |
| Notes | stop names every installed unit too: stopping an inactive target would not reach them. chrony (the host's time, manual 1.13.1) is shown by status but never stopped. |
| Called by | `fabriclib.cli.main` |

| | |
|---|---|
| Purpose | `fabricctl --render-jinja <file.j2> [--vars FILE] [--output FILE\|DIR]`: render one Jinja2 template with fabric's vars and filters, for checking a template or making a config file from them. |
| Inputs | template — the .j2 file; vars_path — the vars file (default <fabric>/config/vars.yaml, chosen by the caller); output — a file or a folder (default: the sudo caller's home). Env SUDO_USER/USER. |

| Called by | `fabriclib.cli._flags` |

### 1.17.25.6.1 `relaxed_settings(vars_, config_dir=None, daemon_json=DAEMON_JSON)`

| | |
|---|---|
| Purpose | the security relaxations this host has turned on, so `fabricctl status` and the web UI can show them while they are active (global Rule 10; manual 1.2.8). | Fails | OSError / ValueError for an unreadable LOWERED_FILE. |
| Feeds | system/show_relaxed_settings (`fabricctl status`); fabric-agent GET /v1/relaxed-settings (the web UI's Overview). |
