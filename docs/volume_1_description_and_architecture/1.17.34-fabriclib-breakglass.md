## 1.17.34.2 `src/fabriclib/breakglass/break_glass_reminder.py`

### 1.17.34.2.1 `break_glass_reminder(config_dir, audit=write_audit)`

| | |
|---|---|
| Purpose | whether the break-glass password's file is still on the host (2.1.6.69): while it is, every administrator is told to copy it into safekeeping and delete it (the console, `fabricctl doctor`). Once it is gone, its removal is audited once (BREAK_GLASS_FILE_REMOVED) and the record dropped. |
| Inputs | config_dir — the install's config folder (<config>/break-glass.json, written by write_break_glass_file); audit — write_audit (tests give their own). |
| Returns | {"path", "text"} while the file is there; None when there is no record or the file is gone. |
| Fails | OSError other than a missing record when the record cannot be read or removed, or the audit written. |
| Feeds | system/host_reminders (the console, through fabric-agent), setup/verify_install (doctor). |
| Called by | `fabriclib.setup.verify_install.run`, `fabriclib.system.host_reminders._reminders` |
