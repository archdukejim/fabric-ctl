### 1.17.19.16.1 `describe_csr(data)`

| | |
|---|---|
| Purpose | Decode a certificate signing request and judge it against fabric's signing policy before anything is signed. |
| Inputs | data — exactly one CSR as PEM, DER bytes or bare base64. |
