## 1.17.27.14 `src/fabriclib/vault/common/pkcs11_session.py`

### 1.17.27.14.1 `pkcs11_session(module, serial, pin, attended=False)`

| | |
|---|---|
| Purpose | context manager giving a logged-in PKCS#11 session on one token; logs out and closes it afterwards. |
| Inputs | module — allowed library path; serial — token serial; pin — the user PIN (str); attended — True when a person asked for this: a token that saw a wrong PIN is then still tried. |
| Returns | yields (PyKCS11 module, session, token info). |
| Fails | ValidationError: the token is not plugged in; its PIN is locked; only one try is left (never spent); it saw a wrong PIN and this is unattended; wrong PIN (CKR_PIN_INCORRECT); any other login refusal. | Feeds | slots/pkcs11 wrap and unwrap, add_security_key_slot. |
