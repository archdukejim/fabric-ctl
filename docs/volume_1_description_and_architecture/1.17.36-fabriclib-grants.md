### 1.17.36.10.1 `sync_grants(v, actor='fabric', source='timer', container='samba', quiet=False)`

| | |
|---|---|
| Purpose | the grants compiled again from the directory as it is (manual 1.6.13.4): at once after a change fabric makes to a group's members (a person's groups, a machine's), and every 5 minutes by the fabric-grants timer for a change made elsewhere (RSAT, samba-tool, a join). | Inputs | v — rendered vars; actor, source — for the audit; container — the DC's container; quiet — bool: never raise (a change that already happened is not undone because the compile failed; the timer retries). |

| Fails | ValidationError from grant_request (the DC not running), unless quiet. |
| Feeds | grants/run_grant_command (`grant sync`, the fabric-grants timer); agent route POST /v1/domain/grants/sync; directory/set_person_group, add_machine, set_host_group_member, sort_machines (at once). |
