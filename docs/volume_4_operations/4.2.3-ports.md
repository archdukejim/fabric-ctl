## 4.2.3.1 Service Ports

| Port | Proto | Handler | Backend |
|------|-------|---------|---------|
| 80 | TCP | nginx | health check · ACME passthrough · HTTPS redirect |
| 443 | TCP | nginx | `step-ca:9000` (`ca.<domain>`) · CA certificate page (`info.<domain>/certs/`; also on 80, and `http://<host_ip>/certs/`) · `/dns-query` (DoH) to `resolver:8053`, or `bind9:8053` with the DNS filter off · Keycloak · webui (`fabric.<domain>`, mTLS → `/opt/webui/run/web.sock`; the webui container publishes no ports, fabric-agent has no network listener) |
| `bind_dns_port` | TCP + UDP | bind9 | DNS for the LAN (`host_ip:bind_dns_port` → container 53); default `53`, `5053` while the DNS filter takes 53 |
| 53 | TCP + UDP | bind9-resolver | The DNS filter (`dns_filter: bind`, the default): the clients' resolver; fabric's names go on to bind9 |
| 853 | TCP | bind9-resolver | DNS-over-TLS for clients, the DNS name's certificate (1.12.2.16); only with the DNS filter on |
| 8053 | TCP | bind9-resolver | plain-HTTP DoH from nginx (fabric_net only, not published) |
| `bind9_doh_port` | TCP | bind9 | plain-HTTP DoH; default `8053` |
| `stepca_port` | TCP | step-ca | internal HTTPS; default `9000` |
| 67 | UDP | kea-dhcp4 (host network) | DHCP; only with `install_kea`, only on the DHCP interfaces |
| 1812, 1813 | UDP | freeradius | RADIUS authentication and accounting; only with `install_freeradius` |
| 88, 135, 389, 445, 464, 636, 3268, 3269, `ad_rpc_ports` (49152–49251) | TCP (88, 389, 464 also UDP) | samba (host network) | The Windows domain controller: Kerberos, RPC, LDAP (CLDAP on UDP), SMB, kpasswd, LDAPS, the global catalog, its RPC range; on every install. Open to the LAN, `firewall_allow`, fabric's container network and the federation's peers (the upstream's and each joined site's address: DC replication, 1.9.8.5) |

`bind9_doh_port`, the resolver's 8053 and `stepca_port` are reached through nginx on fabric_net; they are not published on the host. OpenBao (`vault.<domain>`) is also behind nginx on 443.

> `bind_dns_port` (default `53`) is the Docker host port mapped to BIND9's internal port 53 (`host_ip:bind_dns_port:53`). BIND9 only listens on port 53 inside the container; Docker forwards host traffic on `bind_dns_port` to it. Change it only if another DNS server must keep port 53 on `host_ip`.
