## 4.6.2.1 What it gives an app

An app that speaks OpenID Connect — Proxmox VE, TrueNAS SCALE, Grafana, Nextcloud and most others — can sign people
in through this site's Keycloak instead of keeping its own accounts (owner, 2026-10-06, for 0.6.0). People sign in
with their domain password and their second factor (TOTP), exactly as at fabric's web UI; the app receives their
user name and a `groups` claim holding their domain groups, which it maps to its own roles. Only people Keycloak
admits sign in: the site's people and the organisation's admins (1.6.3.10). Needs Keycloak (`install_keycloak`).

Without single sign-on, many of these apps can still sign people in with their domain account directly (an
*Active Directory* or LDAP realm on the domain controller): the same people, but each app asks for the password
itself and there is no second factor.

## 4.6.2.2 Registering an app

On the fabric host, with the redirect URL the app shows in its OpenID settings:

```bash
sudo fabricctl sso add proxmox --redirect https://pve.example.org:8006
```

It prints the **client id** (`app-proxmox`), the **client secret** — shown once: fabric does not keep it; copy it
into the app now — the **issuer** (`https://sso.<domain>/realms/<realm>`) and its discovery URL. The client is
confidential, uses the authorization-code flow only, accepts exactly the redirect URLs given (https, no wildcards;
repeat `--redirect` for more), and is audited (`SSO_APP_ADD`). The app must trust this network's CA (its root from
`http://info.<domain>/certs/`).

## 4.6.2.3 Proxmox VE

*Datacenter → Permissions → Realms → Add → OpenID Connect Server*: **Issuer URL** the issuer printed, **Realm** a
name of your own, **Client ID** and **Client Key** as printed, **Username Claim** `username`, **Groups Claim**
`groups` with *Autocreate Groups* on. Register Proxmox with the URL of its web interface as the redirect
(`https://<node>:8006`). Then give the realm's groups roles in *Permissions*.

## 4.6.2.4 TrueNAS SCALE

TrueNAS signs people in to its shares through its Active Directory join (4.6.6.6); for its web interface it uses
its own accounts or, on releases that offer it, an OpenID Connect provider with the values printed above.

## 4.6.2.5 Listing and removing apps

```bash
sudo fabricctl sso list
```

```bash
sudo fabricctl sso remove proxmox
```

The list never shows a secret. Removing an app ends every session it held; a secret that leaked is replaced by
removing the app and adding it again.
