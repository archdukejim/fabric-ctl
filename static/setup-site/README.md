# static/setup-site

The stylesheet, script and drawings of web-guided setup's temporary site (manual 1.3.6). The drawings are fabric's own, not
OS screenshots (2.1.8.47). Installed at `fabric/lib/setup-site/`, with `templates/setup-site/`.

| File | What |
|---|---|
| `site.css` | The site's look; light and dark; a phone's width |
| `site.js` | Optional: the live log, reloading on a new phase, Copy buttons, the finish's check; every page works without it |
| `trust-windows.svg`, `trust-macos.svg`, `trust-ubuntu.svg` | Trusting fabric's root, per OS |
| `dns-windows.svg`, `dns-macos.svg`, `dns-ubuntu.svg` | Sending the domain's names to fabric's DNS, per OS |
